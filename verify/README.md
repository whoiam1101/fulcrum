# verify

Formal verification, three layers (docs/ARCHITECTURE.md §6.1):

| Folder | Layer | Tool |
|---|---|---|
| `../src/proofs/` | 1 | Kani proof harnesses, run with `cargo kani` from the repository root |
| `sollya/` | 2 | approximation error bounds |
| `gappa/` | 2 | rounding error bounds; `*.g` are generated by `tools/gen-tables` |
| `lean/` | 3 | Lean 4 spec and proofs; Aeneas extraction of `src/kernel.rs` and `src/wide/` |
